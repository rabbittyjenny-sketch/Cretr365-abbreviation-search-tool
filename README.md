# KUM-TEM. (คำเต็ม) — UN-SHORT ตัวย่อให้เป็นคำเต็ม

> *Alphabet soup? Chill out... I’ll spell 'em out.*

ตัวย่อที่ยุ่งยาก? ไม่อยากยืนงง ก็ส่งมาให้ยืด — รวมคำเต็มๆ ของหลากหลายกลุ่มที่ใช้กัน
เพื่อให้ชาว Creatr365 สบายยยย สบายยย

เว็บแอปสไตล์ doodle บนกระดาษ แสดงผลเป็นหน้าจอมือถือ เปิดได้ทุกอุปกรณ์ และฝังในเว็บอื่นด้วย `<iframe>` ได้

- **ค้นหาแบบให้คะแนน** — ตรงทั้งคำ > ขึ้นต้นเหมือนกัน > มีคำนั้นอยู่ > คำอ่านไทย > สะกดใกล้เคียง
- **พิมพ์ผิดก็เจอ** — `gvm` → GMV, `raos` → ROAS, `เด็ดแอร์` → Dead Air
- **ลืมสลับภาษาก็เจอ** — `เทอ` (พิมพ์ gmv ตอนแป้นเป็นภาษาไทย) → GMV
- **ไม่ขึ้นว่า "ไม่พบ"** — ถ้าไม่ตรงคำไหนเลย จะแสดงคำที่สะกดใกล้เคียงที่สุดแทน
- **ต่อท้ายด้วยคำในกลุ่มเดียวกัน** เรียงจากคำที่ใกล้กับสิ่งที่พิมพ์ที่สุดก่อน
- **ปุ่มลำโพงอ่านคำเต็ม** เช่น SOW → "Scope of Work", EBITDA → "Earnings Before Interest, Taxes, Depreciation and Amortization" (ไม่อ่านตัวย่อ ไม่อ่านคำอธิบาย) ส่วนคำอ่านตัวย่อแสดงในวงเล็บ เช่น (เอส-โอ-ดับเบิลยู)
- **ปุ่มบ้าน** มุมซ้ายบนทุกหน้า กลับหน้าแรกได้ทันที
- สมุดคำ (บันทึกในเครื่อง), ดัชนี A–Z, 18 คำที่ต้องรู้, ภาคผนวกและแหล่งที่มาครบ

## เนื้อหามาจากไหน

ทุกคำอ่านตรงจาก `content/glossary.md` (Creatr365 Master Glossary v2) ตอน build
**อยากแก้/เพิ่มคำ → แก้ไฟล์นี้ไฟล์เดียว** แล้ว push — ตารางในหมวด 1–12 จะกลายเป็นรายการคำเอง

- คำค้นเพิ่มเติม (คำไทยที่คนพิมพ์กันบ่อย คำสะกดอื่น) อยู่ที่ `src/data/aliases.ts` — มีผลกับการค้นหาเท่านั้น ไม่แสดงเป็นเนื้อหา
- รายการที่ซ้ำกันในต้นฉบับ (KOL, Add to Cart, Stay Duration, Min/Max Rate, Glossary 18 คำ) ถูกรวมเป็นคำเดียว
- ข้อความที่ชี้กลับไปในเอกสาร (เช่น "ที่มา: Module 6", "ดูหมวด 12") ถูกตัดออกตอนแสดงผลอัตโนมัติ

## เพิ่มคำใหม่ในอนาคต

แก้ไฟล์ `content/glossary.md` (บนหน้าเว็บ GitHub กดรูปดินสอแก้ได้เลย) แล้วกด Commit — Vercel จะ build ใหม่ให้เองในไม่กี่นาที

1. หาหมวดที่ต้องการ (หัวข้อ `# **1\. ...**` ถึง `# **10\. ...**`) แล้วเพิ่มแถวใหม่ต่อท้ายตารางของหมวดนั้น รูปแบบ 4 ช่อง คั่นด้วย `|`:

   ```
   | ABC **อ่านว่า:** เอ-บี-ซี | Alphabet Business Code (คำแปลไทย) | ความหมายสั้นๆ | **เกณฑ์/ตัวเลข:** ... **เทคนิค:** ... **ดูได้ที่/ใช้กับ:** ... |
   ```

   - ช่อง 1 = ตัวย่อ + `**อ่านว่า:**` + คำอ่าน (หลายแบบใช้ ` / ` คั่น เช่น `CR / CVR **อ่านว่า:** ซี-อาร์ / ซี-วี-อาร์`)
   - ช่อง 2 = **คำเต็มภาษาอังกฤษ** (ปุ่มลำโพงจะอ่านส่วนนี้) ตามด้วยคำแปลไทยในวงเล็บ
   - ช่อง 3 = ความหมาย, ช่อง 4 = รายละเอียด (ไม่มีให้ใส่ `—`)
   - ถ้าเป็นข้อมูลที่ยังไม่ยืนยัน ใส่ `\[ยังไม่ยืนยันแหล่ง\]` ได้ จะขึ้นเป็นป้ายสีส้ม
2. (ไม่บังคับ) ถ้าอยากให้ค้นด้วยคำไทย/คำสะกดอื่นได้ เพิ่มใน `src/data/aliases.ts` เช่น `abc: ["เอบีซี", "คำไทย"]`
3. อยากเพิ่มหมวดใหม่ ใช้หัวข้อ `# **13\. ชื่อหมวด (English name)**` แล้วตามด้วยตาราง 4 ช่องแบบเดียวกัน (และวางรูป `category-13` ได้)
4. แหล่งอ้างอิงใหม่: เพิ่มบรรทัด `· [ชื่อแหล่ง](ลิงก์)` ใต้หัวข้อ `# **แหล่งที่มา**` ท้ายไฟล์

## รันในเครื่อง

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm test         # ทดสอบการค้นหา/การอ่านเสียง
npm run build    # build ไปที่ dist/
```

## Deploy บน Vercel

1. push โฟลเดอร์นี้ขึ้น GitHub
2. ที่ vercel.com → **Add New… → Project** → เลือก repo นี้
3. Vercel จะเห็นเป็น **Vite** เอง (ค่าใน `vercel.json`: build `npm run build`, output `dist`) → กด **Deploy**

ไม่ต้องตั้ง environment variable ใดๆ ไม่มี server / database

## ฝังในเว็บอื่น

```html
<iframe
  src="https://YOUR-APP.vercel.app/?embed=1"
  title="KUM-TEM คำเต็ม"
  style="width:100%;max-width:420px;height:760px;border:0;display:block;margin:0 auto"
  loading="lazy"></iframe>
```

- `?embed=1` (หรือเมื่ออยู่ใน iframe) จะตัดกรอบมือถือออก ให้แอปเต็มกรอบ iframe และไม่โชว์หน้าแนะนำ
- ลิงก์ตรงไปที่คำ: `/?t=gmv` · ค้นหาไว้ล่วงหน้า: `/?q=roas` · หมวด: `/?c=5` · 18 คำ: `/?p=must`
- `vercel.json` ตั้ง `frame-ancestors *` ไว้ให้ฝังได้ทุกโดเมน ถ้าอยากจำกัดให้เปลี่ยนเป็นโดเมนของคุณ

## โครงสร้าง

```

src/lib/search.ts          ระบบค้นหา/จัดอันดับ/สะกดใกล้เคียง
src/lib/keyboard.ts        แปลงแป้นพิมพ์ไทย ↔ อังกฤษ
src/lib/speech.ts          ปุ่มฟังเสียง (อ่านเฉพาะคำ)

src/components/doodles.tsx ภาพ doodle สำรองทั้งหมด
src/screens/*              หน้าจอต่างๆ
src/styles/app.css         สไตล์ทั้งหมด (สีอยู่ที่ :root ด้านบนไฟล์)
```
